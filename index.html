How it works

The Python backend processes your image with a pretrained MobileNetV2 neural network. JavaScript sends the image to the API and displays the returned predictions.

Predictions are model estimates, not guaranteed facts. The model recognizes categories from its training labels and may misclassify unfamiliar images.
